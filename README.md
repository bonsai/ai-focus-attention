# ai-focus-attention

Agent skill encoding principles of human attention and focus in the age of AI tools.

## What this skill does

- Human deep attention does not scale with AI multitasking capacity
- Prefer concentrating on one high-value hard problem over many parallel shallow threads
- Use AI tools to accelerate the focused path, not to maximize open projects
- Maintain calibrated wonder: the frontier still contains many unsolved problems

## Usage

Drop `SKILL.md` into an agent skills directory (e.g. `.grok/skills/ai-focus-attention/`).

The skill activates on prioritization, multitasking with AI assistance, attention management, and related topics.

## Source

Distilled from public reflections of a new-grad engineer after one year at OpenAI.
